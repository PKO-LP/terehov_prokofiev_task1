## Версия и среда
Проверяемая версия: исправленная 0.3.1 (из папки Комплект_0_3_1 / После_исправления). Среда: <ОС Windows / macOS>, Python 3 с библиотекой Tkinter, запуск из терминала VS Code. Начальные условия перед каждым тестом: новый запуск либо выполненный полный сброс.
## Регрессионная проверка
После внесения исправлений в 0.3.1 проверены прежние функции: корректность увеличения счётчика на 1, форматирование даты и времени при приёме заявки, циклический переход статусов (Новая -> В работе -> Готово -> Новая), увеличение счётчика «Закрыто заявок» при переходе в «Готово» и штатное закрытие окна без ошибок в терминале.
## Критерии приёмки
Соответствие всем пунктам ТРЕБОВАНИЯ.txt и дополнению для версии 0.3.1: блокировка приёма на 10-й заявке с надписью «Лимит: 10», полный сброс всех полей кнопкой «Сбросить» и отсутствие регрессии в базовом функционале.
## Что реально проверено
На версии 0.3.0 зафиксированы расхождения по тестам T-01 (на 10-м нажатии кнопка осталась активной, принято 11) и T-02 (после сброса остались статус «Готово» и закрыто 1). На передаваемой копии версии 0.3.1 выполнены все тесты T-01 — T-04, все проверки пройдены успешно.
